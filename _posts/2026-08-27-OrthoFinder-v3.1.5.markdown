### Bug Fixes
- Fixed packaging and installation issues for OrthoFinder utility scripts in pip/conda environments.
- Improved robustness of utility scripts, including recursive directory handling, archive processing, and compatibility with ETE4 ultrametric tree generation.
- Added several new command-line utilities and enhanced existing tools for transcript processing, orthogroup gene counts, HOG FASTA generation, and tree ID conversion.
