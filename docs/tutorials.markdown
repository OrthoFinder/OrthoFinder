These tutorials take you from getting the input files to interpreting the results of OrthoFinder.
If you are new to OrthoFinder, read them in this order:

1. [Getting Input Data]({{ site.baseurl }}/tutorials/gettting-input-data/): download the proteomes of your species from Ensembl, NCBI or Phytozome, and keep one transcript per gene.
2. [Beginner Tutorial]({{ site.baseurl }}/tutorials/beginner-tutorial/): install OrthoFinder, run it on the example data, and explore its results.
3. [Guide to Results]({{ site.baseurl }}/tutorials/guide-to-results/): what each results file contains.

[Understanding Orthology]({{ site.baseurl }}/tutorials/understand-orthology/) explains orthologs, paralogs and orthogroups, and why OrthoFinder works with orthogroups.
For more than about 100 species, or to add species to an earlier analysis, see the [Advanced Tutorial]({{ site.baseurl }}/tutorials/advanced-tutorial/);
for the options to stop and restart an analysis, run the sequence searches yourself, or choose other programs, see [Advanced Usage]({{ site.baseurl }}/tutorials/advanced-usage/).

📄 All the tutorials in one document, for the latest release:
[OrthoFinder3_tutorial.pdf](https://github.com/OrthoFinder/OrthoFinder/releases/latest/download/OrthoFinder3_tutorial.pdf)
